Шаг 8. Проведение документа (движение в регистр)
Ты уже привязал регистр к документу, теперь нужен код, который пишет движения.

Конфигуратор → Документы → ВыдачаГотовыхДокументов → вкладка Прочее → Модуль объекта (или правая кнопка по документу → Открыть модуль объекта).
Вставь:
bsl
Процедура ОбработкаПроведения(Отказ, РежимПроведения)
	Движения.ЗадолжностьКлиента.Записывать = Истина;
	Для Каждого Строка Из Услуги Цикл
		Движение = Движения.ЗадолжностьКлиента.Добавить();
		Движение.ВидДвижения = ВидДвиженияНакопления.Приход;
		Движение.Период = Дата;
		Движение.Клиент = Клиент;
		Движение.Услуга = Строка.Услуга;
		Движение.ВидДокумента = Строка.ВидДокумента;
		Движение.Сумма = Строка.Стоимость;
	КонецЦикла;
КонецПроцедуры

Шаг 9. Код кнопки «Выдать документы»
Что делает: для каждой отмеченной строки создаёт и проводит документ ВыдачаГотовыхДокументов, записывает его в колонку «Документ выдачи», ставит «Проведен» и выводит количество в «Всего обработано».

Конфигуратор → форма обработки → вкладка Модуль.
Найди процедуру ВыдатьДокументы и замени её на этот код:
bsl
&НаКлиенте
Процедура ВыдатьДокументы(Команда)
	ВыдатьДокументыНаСервере();
КонецПроцедуры

&НаСервере
Процедура ВыдатьДокументыНаСервере()
	Количество = 0;
	Для Каждого Строка Из Объект.Заявки Цикл
		Если Строка.Выбрать И НЕ Строка.Проведен Тогда
			Док = Документы.ВыдачаГотовыхДокументов.СоздатьДокумент();
			Док.Дата = ТекущаяДата();
			Док.Клиент = Строка.Клиент;
			Док.ДатаГотовности = Строка.ДатаГотовности;
			НоваяСтрока = Док.Услуги.Добавить();
			НоваяСтрока.Услуга = Строка.Услуга;
			НоваяСтрока.ВидДокумента = Строка.ВидДокумента;
			НоваяСтрока.Стоимость = Строка.Стоимость;
			Док.Записать(РежимЗаписиДокумента.Проведение);
			Строка.ДокументВыдачи = Док.Ссылка;
			Строка.Проведен = Док.Проведен;
			Количество = Количество + 1;
		КонецЕсли;
	КонецЦикла;
	Объект.ВсегоОбработано = Объект.ВсегоОбработано + Количество;
КонецПроцедуры
F7, запусти (F5), подбери заявки, нажми «Выдать документы».
Ожидаемо: у обеих строк появится ссылка на документ, галочка «Проведен», «Всего обработано» = 2.
